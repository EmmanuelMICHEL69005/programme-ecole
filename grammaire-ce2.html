Je retiens

🔤 Nom : désigne une personne, un animal, une chose (chat, maison, Lucas)
🔵 Déterminant : accompagne le nom (le, la, les, un, une, des, mon, ma…)
🟢 Verbe : exprime une action ou un état (manger, être, courir)
🟡 Adjectif : précise le nom (grand, rouge, joli)
🔴 Pronom : remplace un nom (je, tu, il, elle, nous, vous, ils, elles)
📏 GN : déterminant + nom (+ adjectif éventuellement) → le grand chat

Corrigé des exercices

Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Identifier la nature du mot
  1. Quelle est la nature de ce mot ? chat → nom commun
  2. Quelle est la nature de ce mot ? mange → verbe
  3. Quelle est la nature de ce mot ? grand → adjectif
  4. Quelle est la nature de ce mot ? le → déterminant
  5. Quelle est la nature de ce mot ? Paris → nom propre
  6. Quelle est la nature de ce mot ? courent → verbe
  7. Quelle est la nature de ce mot ? ils → pronom personnel
Ex 2 · Le groupe nominal (GN)
  1. Combien ce GN contient-il de mots ? "le petit chien" → 3 mots
  2. Quel est le nom dans ce GN ? "les maisons rouges" → maisons
  3. Quel est l'adjectif dans ce GN ? "une belle fleur" → belle
  4. Choisis le bon déterminant : Quel déterminant convient ? "_____ enfants jouent." → Les
  5. Quel est le déterminant possessif ? "mon chien" → mon
  6. Quel est le nom noyau du GN ? "des fleurs blanches" → fleurs
Ex 3 · Types de phrases
  1. Quel type de phrase est-ce ? "Il pleut aujourd'hui." → déclarative
  2. Quel type de phrase est-ce ? "Viens ici !" → impérative
  3. Quel type de phrase est-ce ? "Est-ce que tu viens ?" → interrogative
  4. Quel type de phrase est-ce ? "Quelle belle journée !" → exclamative
  5. Quel type de phrase est-ce ? "Les oiseaux chantent." → déclarative
Ex 4 · Accord sujet-verbe
  1. Conjugue le verbe "dormir" avec "les chats" : "Les chats _____ dans le jardin." → dorment
  2. Conjugue le verbe "faire" avec "mon frère" : "Mon frère _____ du vélo." → fait
  3. Conjugue le verbe "chanter" avec "nous" : "Nous _____ très bien." → chantons
  4. Elle et moi = quel pronom ? "Elle et moi _____ à l'école." → nous (→ chantons)
  5. Conjugue "jouer" — sujet = le chien et le chat : "Le chien et le chat _____ ensemble." → jouent
Ex 5 · Accord dans le groupe nominal
  1. Comment dit-on au pluriel ? un chat gris (→ deux…) → des chats gris
  2. Quelle est la forme au masculin ? "une grande maison" → masculin singulier → un grand bâtiment
  3. Comment dit-on au singulier ? "les filles sportives" → la fille sportive
  4. Quelle est la forme au pluriel ? "un beau garçon" → pluriel → des beaux garçons
  5. Transforme en masculin pluriel : "la petite fille" → masculin pluriel → les petits garçons
Ex 6 · Vrai ou Faux — grammaire
  1. "mange" est un verbe → Vrai
  2. "le" est un adjectif → Faux "le" est un déterminant
  3. Un GN contient toujours un nom → Vrai
  4. La phrase "Mange ta soupe !" est déclarative → Faux C'est une phrase impérative
  5. Dans les beaux arbres, le mot arbres s'accorde au pluriel → Vrai
  6. "Paris" est un nom commun → Faux "Paris" est un nom propre
  7. Le verbe s'accorde avec le sujet → Vrai
Ex 7 · Associer mot et nature
  1. Associe chaque mot à sa nature.
    • manger ↔ verbe
    • beau ↔ adjectif
    • maison ↔ nom commun
    • une ↔ déterminant
  2. Associe chaque phrase à son type.
    • Il fait froid. ↔ déclarative
    • Ferme la porte ! ↔ impérative
    • Tu viens ? ↔ interrogative
    • Quel beau ciel ! ↔ exclamative
Ex 8 · Identifier le groupe nominal sujet (GNS)
  1. Quel est le groupe nominal sujet (GNS) ? "Le petit chat noir dort." → Le petit chat noir
  2. Quel est le GNS ? "Mes amis et moi jouons au foot." → Mes amis et moi
  3. Quel est le GNS ? "La maîtresse explique." → La maîtresse
  4. Quel est le GNS ? "Ce beau livre raconte une histoire." → Ce beau livre
  5. Quel est le GNS ? "Les enfants de la classe chantent." → Les enfants de la classe
Ex 9 · Nature vs Fonction
  1. Ce mot est de quelle nature ? "rapidement" → adverbe
  2. Quelle est la fonction de "Le soleil" ? "Le soleil" dans "Le soleil brille" → sujet
  3. Quelle est la fonction de "une pomme" ? "une pomme" dans "Je mange une pomme" → COD
  4. Quelle est la fonction de "à Paris" ? "à Paris" dans "Je vais à Paris" → CCL (complément circonstanciel de lieu)
  5. Ce mot est de quelle nature ? "beau" dans "un beau jardin" → adjectif qualificatif
Ex 10 · Classer les compléments : CCL / CCT / CCM
  1. Classe chaque groupe selon sa nature de complément.
    • CCL (lieu) : à Paris, dans la forêt, chez moi, sous la table
    • CCT (temps) : demain, le lundi, à midi, pendant l'été
    • CCM (manière) : rapidement, avec soin, doucement, en silence
Ex 11 · La phrase négative
  1. Quelle est la phrase négative ? "Je mange des carottes." → Je ne mange pas de carottes.
  2. Cette phrase est… "Tom ne court jamais." → négative
  3. Quels mots forment la négation ? "Elle n'aime pas le lait." → n' … pas
  4. Quelle est la phrase affirmative ? "Il ne chante pas." → Il chante.
  5. Transforme avec "ne … jamais". "Lou regarde la télé." → Lou ne regarde jamais la télé.
Ex 12 · Trouver l'infinitif du verbe
  1. Quel est l'infinitif du verbe ? "Les enfants courent dans la cour." → courir
  2. Quel est l'infinitif du verbe ? "Nous finissons nos devoirs." → finir
  3. Quel est l'infinitif du verbe ? "Tu prends ton sac." → prendre
  4. Quel est l'infinitif du verbe ? "Elle va au marché." → aller
  5. Quel est l'infinitif du verbe ? "Ils font un gâteau." → faire
Ex 13 · Remplacer le sujet par un pronom
  1. Par quel pronom remplacer le sujet ? "Les filles jouent." → Elles
  2. Par quel pronom remplacer le sujet ? "Mon frère lit." → Il
  3. Par quel pronom remplacer le sujet ? "Le chien et le chat dorment." → Ils
  4. Par quel pronom remplacer le sujet ? "Ta sœur et toi chantez." → Vous
  5. Par quel pronom remplacer le sujet ? "La voisine arrose ses fleurs." → Elle
