4 exercices interactifs de maths en 4e, soit 16 questions : symétrie centrale (demi-tour), parallélogrammes, translations, repérage. Chaque réponse est corrigée tout de suite, avec une explication en cas d’erreur. Gratuit, sans inscription et sans publicité.

Je retiens

🔄 Demi-tour de centre O : O est le milieu de [AA']
➡️ Translation : conserve longueurs, angles et alignements · transforme une droite en droite parallèle
▱ Parallélogramme : côtés opposés égaux · diagonales qui se coupent en leur milieu

Ex 1 Symétrie centrale (demi-tour)

  1. Le symétrique de A par rapport à O est A' tel que…
    • A' = A
    • A' est à côté de A
    • O est le milieu de [AA']
    • O est le milieu de [AB]
  2. Un demi-tour conserve…
    • les angles seulement
    • les longueurs et les angles
    • les longueurs seulement
    • rien
  3. Le symétrique d'un cercle par rapport à son centre est…
    • le même cercle
    • un cercle plus grand
    • un segment
    • une ellipse
  4. Un demi-tour transforme un segment en…
    • un point
    • un segment de même longueur
    • un segment deux fois plus long
    • une droite

Ex 2 Parallélogrammes

  1. Un quadrilatère dont les diagonales ont le même milieu est…
    • un carré
    • un losange
    • un parallélogramme
    • un trapèze
  2. Dans un parallélogramme ABCD, si AB = 5 cm alors CD = …
    • 10 cm
    • 2,5 cm
    • 5 cm
    • 7 cm
  3. Un parallélogramme qui a un angle droit est un…
    • losange
    • rectangle
    • trapèze
    • triangle
  4. Les diagonales d'un losange sont…
    • confondues
    • parallèles
    • perpendiculaires
    • égales

Ex 3 Translations

  1. Une translation conserve…
    • les aires seulement
    • les angles
    • les points fixes
    • rien
  2. Quel est l'effet d'une translation sur une droite ?
    • elle la laisse inchangée
    • elle la transforme en cercle
    • elle la transforme en droite parallèle
    • elle la transforme en point
  3. AB + BC = ?
    • AB
    • AC
    • BC
    • CA
  4. L'opposé du vecteur AB est le vecteur…
    • 0
    • AB
    • BA
    • CB

Ex 4 Repérage

  1. Dans un repère, A(2 ; 3) : son abscisse est…
    • 2
    • 3
    • 5
    • −2
  2. Le milieu de [AB] avec A(1 ; 2) et B(3 ; 4) est…
    • (1 ; 1)
    • (2 ; 2)
    • (2 ; 3)
    • (4 ; 6)
  3. Distance de O(0 ; 0) à A(3 ; 4) ?
    • 12
    • 25
    • 5
    • 7
  4. Le symétrique de A(2 ; 3) par rapport à l'origine O est…
    • (2 ; −3)
    • (3 ; 2)
    • (−2 ; −3)
    • (−3 ; 2)

Corrigé des exercices

Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Symétrie centrale (demi-tour)
  1. Le symétrique de A par rapport à O est A' tel que… → O est le milieu de [AA']
  2. Un demi-tour conserve… → les longueurs et les angles
  3. Le symétrique d'un cercle par rapport à son centre est… → le même cercle
  4. Un demi-tour transforme un segment en… → un segment de même longueur
Ex 2 · Parallélogrammes
  1. Un quadrilatère dont les diagonales ont le même milieu est… → un parallélogramme
  2. Dans un parallélogramme ABCD, si AB = 5 cm alors CD = … → 5 cm
  3. Un parallélogramme qui a un angle droit est un… → rectangle
  4. Les diagonales d'un losange sont… → perpendiculaires
Ex 3 · Translations
  1. Une translation conserve… → les angles
  2. Quel est l'effet d'une translation sur une droite ? → elle la transforme en droite parallèle
  3. AB + BC = ? → AC
  4. L'opposé du vecteur AB est le vecteur… → BA
Ex 4 · Repérage
  1. Dans un repère, A(2 ; 3) : son abscisse est… → 2
  2. Le milieu de [AB] avec A(1 ; 2) et B(3 ; 4) est… → (2 ; 3)
  3. Distance de O(0 ; 0) à A(3 ; 4) ? → 5
  4. Le symétrique de A(2 ; 3) par rapport à l'origine O est… → (−2 ; −3)
