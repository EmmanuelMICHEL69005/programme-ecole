🔑 Prop. subordonnée relative : qui / que / dont / où
— qui = sujet de la sub. · que = COD · dont = de quoi/qui · où = lieu/temps
🔑 Phrase complexe : plusieurs propositions = plusieurs verbes conjugués
📌 Juxtaposition (,) · Coordination (conj. coord.) · Subordination (conj. subord.)

Corrigé des exercices

Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Choisir le bon pronom relatif
  1. Pronom relatif pour compléter (le livre = COD) "Le livre ___ j'ai lu est passionnant." → que
  2. Pronom relatif (la fille = sujet de "chante") "La fille ___ chante est ma cousine." → qui
  3. Pronom relatif (parler de ce film → dont) "Le film ___ il parle est sorti hier." → dont
  4. Pronom relatif (lieu de naissance) "Le pays ___ elle est née est magnifique." → où
  5. Pronom relatif (COD) "L'homme ___ tu as rencontré est professeur." → que
  6. Pronom relatif (être fier de → dont) "Les photos ___ il est fier sont encadrées." → dont
Ex 2 · Identifier la proposition subordonnée relative
  1. Quelle est la proposition subordonnée relative ? "Le chat qui dort sur le canapé est à moi." → "qui dort sur le canapé"
  2. Quelle est la proposition subordonnée relative ? "J'aime les films que tu m'as recommandés." → "que tu m'as recommandés"
  3. Quelle est la proposition subordonnée relative ? "La maison où ils habitent est grande." → "où ils habitent"
  4. Quelle est la proposition subordonnée relative ? "Il cherche la personne dont il a besoin." → "dont il a besoin"
Ex 3 · Type de liaison entre propositions
  1. Type de liaison : "Il est venu, mais il est reparti." → coordination (mais)
  2. Type de liaison : "Il est venu ; il est reparti." → juxtaposition (;)
  3. Type de liaison : "Je pense qu'il viendra." → subordination (que)
  4. Type de liaison : "Elle mange, elle lit, elle écoute." → juxtaposition (,)
  5. Type de liaison : "Il sort bien qu'il soit fatigué." → subordination (bien que)
Ex 4 · Fonctions avancées
  1. Fonction de "que" dans la subordonnée : "Le livre que j'ai lu." → COD de "ai lu"
  2. Fonction de "qui" dans la subordonnée : "La fille qui chante est belle." → sujet de "chante"
  3. Fonction de "où" dans la subordonnée : "L'endroit où nous nous rencontrâmes." → CC de lieu
  4. Fonction de "dont" dans la subordonnée : "Ce dont j'ai besoin." → COI (avoir besoin de)
Ex 5 · Subordination — type de subordonnée
  1. La subordonnée "qu'il viendra" est… "Je sais qu'il viendra." → subordonnée conjonctive (complément du verbe)
  2. La subordonnée "qui aboie" est… "Le chien qui aboie ne mord pas." → subordonnée relative (épithète du sujet)
  3. La subordonnée "parce qu'il pleut" est… "Parce qu'il pleut, je reste." → subordonnée de cause
  4. La subordonnée "quand il arriva" est… "Quand il arriva, elle chanta." → subordonnée de temps
Ex 6 · Vrai ou Faux
  1. "Qui" pronom relatif est toujours le sujet de la proposition subordonnée → Vrai
  2. "Que" pronom relatif est toujours le COD de la proposition subordonnée → Vrai
  3. "Dont" peut remplacer "de qui" ou "de quoi" → Vrai
  4. Une proposition principale peut fonctionner seule → Vrai
  5. Une proposition subordonnée peut fonctionner seule → Faux Une proposition subordonnée dépend de la principale — elle ne peut pas fonctionner seule
  6. "Où" pronom relatif exprime toujours le lieu → Faux "Où" peut exprimer le lieu OU le temps : "le jour où il arriva" (temps)
Ex 7 · Associe le pronom relatif à sa fonction
  1. Relie chaque élément à celui qui lui correspond.
    • qui (pronom relatif) ↔ sujet de la subordonnée
    • que (pronom relatif) ↔ COD de la subordonnée
    • dont (pronom relatif) ↔ de qui / de quoi (COI ou compl. du nom)
    • où (pronom relatif) ↔ lieu ou temps dans la subordonnée
    • proposition principale ↔ peut fonctionner seule
    • proposition subordonnée ↔ dépend de la principale
Ex 8 · Identifier le type de subordonnée conjonctive
  1. Type de subordonnée conjonctive : "Il part parce qu'il est fatigué." → subordonnée de cause
  2. Type de subordonnée conjonctive : "Appelle-moi quand tu arrives." → subordonnée de temps
  3. Type de subordonnée conjonctive : "Je lis pour que tu comprennes." → subordonnée de but
  4. Type de subordonnée conjonctive : "Bien qu'il pleuve, il sort." → subordonnée d'opposition / concession
  5. Type de subordonnée conjonctive : "Si tu travailles, tu réussiras." → subordonnée de condition
Ex 9 · Choisir le bon pronom relatif (révision)
  1. Pronom relatif (le livre = COD) "Il y a un livre ___ je n'ai pas encore lu." → que (COD)
  2. Pronom relatif (parler de → dont) "L'ami ___ je te parle est gentil." → dont (COI de parle)
  3. Pronom relatif (lieu) "La ville ___ j'habite est belle." → où (CC lieu)
  4. Pronom relatif (sujet de "travaille") "L'élève ___ travaille bien réussira." → qui (sujet)
  5. Pronom relatif (COD de "chantes") "La chanson ___ tu chantes est jolie." → que (COD)
Ex 10 · Classer les subordonnées
  1. Classer chaque groupe de mots selon le type de subordonnée
    • Relative : qui mange, que j'aime, dont tu parles, où tu habites
    • Cause : parce qu'il pleut, puisque tu veux, car il fait froid
    • Temps : quand j'arrive, lorsqu'il part, dès que tu viens
    • But : pour que tu comprennes, afin qu'il réussisse
Ex 11 · Le complément circonstanciel
  1. Ce complément circonstanciel indique… "Nous jouons dans le jardin." → dans le jardin → le lieu
  2. Ce complément circonstanciel indique… "Le train partira à midi." → à midi → le temps
  3. Ce complément circonstanciel indique… "Il marche lentement." → lentement → la manière
  4. Ce complément circonstanciel indique… "Elle reste à l'intérieur à cause de la pluie." → à cause de la pluie → la cause
  5. Ce complément circonstanciel indique… "Chaque matin, je bois un verre de lait." → Chaque matin → le temps
Ex 12 · La classe grammaticale des mots
  1. Quelle est la classe grammaticale de ce mot ? "Elle porte une jolie robe." → jolie → adjectif qualificatif
  2. Quelle est la classe grammaticale de ce mot ? "Nous partirons demain." → Nous → pronom personnel
  3. Quelle est la classe grammaticale de ce mot ? "Le chat dort sous la table." → sous → préposition
  4. Quelle est la classe grammaticale de ce mot ? "Il pleut, mais il fait doux." → mais → conjonction de coordination
  5. Quelle est la classe grammaticale de ce mot ? "Il court très vite." → très → adverbe
