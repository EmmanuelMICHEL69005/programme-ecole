🧪 Substituer : remplacer la lettre par un nombre, puis calculer
⚖️ Une égalité est vraie si les deux membres sont égaux pour la valeur donnée
🔁 k(a + b) = ka + kb · on réduit : 3x + 5x = 8x

Ex 1 · Produire une formule
  1. Le double d'un nombre n s'écrit… → 2n

  2. Calcule 2a + 3b pour a = 4 et b = 2 → 14

Ex 3 · Tester une égalité

  2. L'égalité 2x + 5 = 15 est-elle vraie pour x = 4 ? → Non
  3. Pour quelle valeur x + 9 = 12 est-elle vraie ? → x = 3
  4. L'égalité a + b = b + a est vraie… → toujours
