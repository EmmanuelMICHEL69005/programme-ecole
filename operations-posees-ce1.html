Je retiens

➖ Soustraction avec emprunt : si je ne peux pas soustraire, j'emprunte à la colonne d'à côté
🔍 Je vérifie : Addition + Soustraction = je retrouve le départ

Ex 4 · Vrai ou Faux — opérations
  1. 213 + 145 = 358 : 213 + 145 = 358 → Vrai
  2. 578 − 243 = 325 : 578 − 243 = 325 → Faux 578 − 243 = 335
  3. 247 + 136 = 383 : 247 + 136 = 383 → Vrai
  4. 467 + 165 = 622 : 467 + 165 = 622 → Faux 467 + 165 = 632
  5. 900 − 400 = 500 : 900 − 400 = 500 → Vrai
  6. 358 − 145 = 213 : 358 − 145 = 213 → Vrai On vérifie l'addition : 213 + 145 = 358 ✅
Ex 5 · Trouver l'erreur
  1. Marie calcule 158 + 234 et trouve 382. Marie a-t-elle bon ? → Non, il faut 392
  2. Paul calcule 375 + 248 et trouve 623. Paul a-t-il bon ? → Oui, 623 est correct
  3. Lola calcule 697 − 354 et trouve 353. Lola a-t-elle bon ? → Non, il faut 343
  4. Dans 247 + 136 = 383, quel chiffre est au rang des unités du résultat ? → 3
