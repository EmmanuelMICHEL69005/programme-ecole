Je retiens

🌡️ Un nombre relatif a un signe : positif (+) ou négatif (−)
🔄 L'opposé de +7 est −7 ; l'opposé de −4 est +4
📏 La valeur absolue = la distance à zéro (toujours positive) : |−5| = 5
➕ Additionner deux relatifs de même signe : on ajoute, on garde le signe
➖ Soustraire, c'est ajouter l'opposé : 3 − (−5) = 3 + 5 = 8

Corrigé des exercices

Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Comprendre les nombres relatifs
  1. Quel est l'opposé de −9 ? → +9
  2. Combien vaut la valeur absolue |−12| ? → 12
  3. Un sous-marin est à −80 m. Cela signifie… → 80 m sous le niveau de la mer
  4. Parmi ces nombres, lequel est strictement négatif ? → −0,5
Ex 2 · Comparer et ranger
  1. Quel est le plus petit : −3 ou −7 ? → −7
  2. Range dans l'ordre croissant : −2 ; 5 ; −6 ; 0 → −6 ; −2 ; 0 ; 5
  3. Sur une droite graduée, le point d'abscisse −4 est… → à gauche de 0
  4. Quel signe compléter : −8 … −1 ? → <
Ex 3 · Additionner des nombres relatifs
  1. (−6) + (−5) = ? → −11
  2. (−8) + (+3) = ? → −5
  3. (+9) + (−9) = ? → 0
  4. (−4) + (+10) + (−2) = ? → +4
Ex 4 · Soustraire et enchaîner
  1. 7 − (−5) = ? → 12
  2. (−3) − (+8) = ? → −11
  3. (−2) − (−9) = ? → +7
  4. Simplifie l'écriture : 5 + (−3) − (−2) → 5 − 3 + 2
Ex 5 · Critères de divisibilité
  1. Quel nombre est divisible par 3 ? → 123
  2. Quel nombre est divisible par 9 ? → 459
  3. Quel nombre est divisible par 5 ? → 2 345
  4. Quel nombre est divisible par 4 ? → 316
  5. Quel nombre est un multiple de 7 ? → 91
