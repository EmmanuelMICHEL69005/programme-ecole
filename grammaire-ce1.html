Je retiens

🔑 Nom : désigne une personne, un animal, une chose (chat, maison, Lucas)
🔑 Verbe : exprime une action ou un état (mange, est, court)
🔑 Adjectif : décrit le nom (grand, rouge, joli)
🔑 Sujet : "qui ?" ou "qu'est-ce qui ?" fait l'action
📌 La phrase commence par une majuscule et se termine par un point

Ex 2 · Identifier le verbe
  1. Quel est le verbe ? "Le chien court dans le jardin." → court
  2. Quel est le verbe ? "La petite fille mange une pomme." → mange
  3. Quel est le verbe ? "Mon chat dort sur le canapé." → dort
  4. Quel est le verbe ? "Les enfants jouent au ballon." → jouent
  5. Quel est le verbe ? "Elle est très contente." → est
Ex 3 · Identifier le sujet
  1. Qui fait l'action ? "Le chat mange sa pâtée." → Le chat
  2. Qui fait l'action ? "Les enfants courent vite." → Les enfants
  3. Qui fait l'action ? "Ma petite sœur pleure." → Ma petite sœur
  4. Qui fait l'action ? "Le soleil brille." → Le soleil
  5. Qui fait l'action ? "Nous mangeons des fruits." → Nous
Ex 4 · Types de phrases
  1. Quel type de phrase ? "Il fait beau aujourd'hui." → déclarative
  2. Quel type de phrase ? "Quelle belle journée !" → exclamative
  3. Quel type de phrase ? "Mange tes légumes !" → impérative
  4. Quel type de phrase ? "Tu viens jouer ?" → interrogative
  5. Quel type de phrase ? "Les enfants jouent dans le parc." → déclarative
  6. Quel type de phrase ? "Viens ici !" → impérative
Ex 5 · Accord sujet-verbe
  1. Forme correcte ? "Le chat ___ (dormir, présent)" → dort
  2. Forme correcte ? "Les oiseaux ___ (chanter, présent)" → chantent
  3. Forme correcte ? "Je ___ (avoir, présent)" → ai
  4. Forme correcte ? "Nous ___ (être, présent)" → sommes
  5. Forme correcte ? "Ma sœur ___ (manger, présent)" → mange
Ex 6 · Vrai ou Faux
  1. Une phrase commence toujours par une majuscule → Vrai
  2. "Le chat" est un groupe nominal (déterminant + nom) → Vrai
  3. "Mange !" est une phrase déclarative → Faux C'est une phrase impérative (ordre)
  4. Dans "Les oiseaux chantent", le sujet est "oiseaux" → Faux Le sujet est "Les oiseaux" (avec le déterminant)
  5. Un adjectif précise le sens d'un nom → Vrai
  6. "Elle est belle." — "belle" est un verbe → Faux "belle" est un adjectif
Ex 7 · Associe le mot à sa nature
  1. Relie chaque élément à celui qui lui correspond.
    • chien ↔ nom commun
    • mange ↔ verbe
    • beau ↔ adjectif
    • le ↔ déterminant
    • Paris ↔ nom propre
    • vite ↔ adverbe

  4. Quelle est la nature de ce mot ? "Léa" → nom propre
  5. Quelle est la nature de ce mot ? "courir" → verbe à l'infinitif
Ex 9 · Type et forme des phrases
  1. Forme négative correcte : "Quelle est la forme négative de 'Il chante' ?" → Il ne chante pas.
  2. Type de phrase : "Quel est le type de 'Ferme la porte !' ?" → impérative
  3. Forme négative correcte : "Quelle est la forme négative de 'Nous mangeons' ?" → Nous ne mangeons pas.
  4. Forme négative correcte : "Quelle est la forme négative de 'Tu joues' ?" → Tu ne joues pas.
  5. Type de phrase : "Quel est le type de 'Est-ce qu'il pleut ?' ?" → interrogative
Ex 10 · Classer : Nom / Verbe / Adjectif
  1. Classe chaque mot dans la bonne catégorie grammaticale.
    • Nom : chien, école, soleil, maison
    • Verbe : courir, manger, dormir, jouer
    • Adjectif : rouge, grand, beau, petit
