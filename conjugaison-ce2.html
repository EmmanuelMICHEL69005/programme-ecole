Je retiens

📝 1er groupe : verbes en -ER (ex : manger, jouer) → je joue, tu joues…
📗 2e groupe : verbes en -IR (ex : finir, grandir) → je finis, tu finis…
🕐 Présent : action qui se passe maintenant
🕑 Imparfait : action passée qui durait (je jouais…)
🕒 Passé composé : avoir/être + participe passé (j'ai joué / je suis allé)
🕓 Futur simple : action à venir, terminaisons -rai, -ras, -ra…

Corrigé des exercices

Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Identifier le groupe du verbe
  1. À quel groupe appartient ce verbe ? manger → 1er groupe (-ER)
  2. À quel groupe appartient ce verbe ? finir → 2e groupe (-IR)
  3. À quel groupe appartient ce verbe ? aller → 3e groupe (irrégulier)
  4. À quel groupe appartient ce verbe ? choisir → 2e groupe (-IR)
  5. À quel groupe appartient ce verbe ? jouer → 1er groupe (-ER)
  6. À quel groupe appartient ce verbe ? venir → 3e groupe (irrégulier)
Ex 2 · Présent de l'indicatif — 1er groupe
  1. Présent — verbe danser, sujet "je" : Je _____ (danser) → danse
  2. Présent — verbe manger, sujet "nous" : Nous _____ (manger) → mangeons
  3. Présent — verbe jouer, sujet "ils" : Ils _____ (jouer) → jouent
  4. Présent — verbe aimer, sujet "tu" : Tu _____ (aimer) → aimes
  5. Présent — verbe chanter, sujet "elle" : Elle _____ (chanter) → chante
  6. Présent — verbe travailler, sujet "vous" : Vous _____ (travailler) → travaillez
Ex 3 · Présent de l'indicatif — être, avoir, aller, faire
  1. Présent de être : Je _____ (être) → suis
  2. Présent de avoir : Tu _____ (avoir) → as
  3. Présent de aller : Il _____ (aller) → va
  4. Présent de faire : Nous _____ (faire) → faisons
  5. Présent de être : Elles _____ (être) → sont
  6. Présent de avoir : Vous _____ (avoir) → avez
Ex 4 · Imparfait
  1. Imparfait — verbe jouer, sujet "je" : Je _____ (jouer) — imparfait → jouais
  2. Imparfait — verbe manger, sujet "il" : Il _____ (manger) — imparfait → mangeait
  3. Imparfait — verbe chanter, sujet "nous" : Nous _____ (chanter) — imparfait → chantions
  4. Imparfait — verbe danser, sujet "elles" : Elles _____ (danser) — imparfait → dansaient
  5. Imparfait — verbe finir, sujet "tu" : Tu _____ (finir) — imparfait → finissais
Ex 5 · Futur simple
  1. Futur simple — verbe partir, sujet "je" : Je _____ (partir) — futur → partirai
  2. Futur simple — verbe jouer, sujet "elle" : Elle _____ (jouer) — futur → jouera
  3. Futur simple — verbe manger, sujet "vous" : Vous _____ (manger) — futur → mangerez
  4. Futur simple — verbe chanter, sujet "ils" : Ils _____ (chanter) — futur → chanteront
  5. Futur simple — verbe finir, sujet "tu" : Tu _____ (finir) — futur → finiras
  6. Futur simple — verbe être, sujet "nous" : Nous _____ (être) — futur → serons
Ex 6 · Passé composé — avec avoir
  1. Participe passé de jouer : J'ai _____ (jouer) → joué
  2. Participe passé de manger : Elle a _____ (manger) → mangé
  3. Participe passé de finir : Nous avons _____ (finir) → fini
  4. Participe passé de choisir : Il a _____ (choisir) → choisi
  5. Participe passé de regarder : Ils ont _____ (regarder) → regardé
  6. Participe passé de danser : Tu as _____ (danser) → dansé
Ex 7 · Quel temps est-ce ?
  1. Associe chaque phrase à son temps.
    • Je mange une pomme. ↔ présent
    • Je mangeais une pomme. ↔ imparfait
    • J'ai mangé une pomme. ↔ passé composé
    • Je mangerai une pomme. ↔ futur simple
  2. Associe chaque verbe à son groupe.
    • jouer ↔ 1er groupe
    • grandir ↔ 2e groupe
    • faire ↔ 3e groupe
    • chanter ↔ 1er groupe
Ex 8 · Valeur du présent
  1. Quelle est la valeur du présent dans cette phrase ? "Il pleut." → fait actuel
  2. Quelle est la valeur du présent dans cette phrase ? "Je me lève à 7h tous les jours." → habitude
  3. Quelle est la valeur du présent dans cette phrase ? "La Terre tourne autour du Soleil." → vérité générale
  4. Quelle est la valeur du présent dans cette phrase ? "Attention, il arrive !" → action en cours
  5. Quelle est la valeur du présent dans cette phrase ? "Si tu travailles, tu réussis." → condition
Ex 9 · Conjuguer au conditionnel présent
  1. Conditionnel présent de "vouloir", sujet "je" : Je _____ (vouloir) — conditionnel présent → voudrais
  2. Conditionnel présent de "pouvoir", sujet "il" : Il _____ (pouvoir) — conditionnel présent → pourrait
  3. Conditionnel présent de "aller", sujet "nous" : Nous _____ (aller) — conditionnel présent → irions
  4. Conditionnel présent de "faire", sujet "tu" : Tu _____ (faire) — conditionnel présent → ferais
  5. Conditionnel présent de "avoir", sujet "vous" : Vous _____ (avoir) — conditionnel présent → auriez
Ex 10 · Indicatif ou Impératif ?
  1. Classe chaque phrase selon son mode.
    • Indicatif : Tu manges., Ils jouent., Nous partons., Elle dort.
    • Impératif : Mange !, Jouez !, Partons !, Dors !
Ex 11 · Présent — dire, venir, prendre, pouvoir, voir
  1. Présent de dire : Vous _____ (dire) → dites
  2. Présent de venir : Ils _____ (venir) → viennent
  3. Présent de prendre : Nous _____ (prendre) → prenons
  4. Présent de pouvoir : Tu _____ (pouvoir) → peux
  5. Présent de voir : Je _____ (voir) → vois
Ex 12 · Imparfait — être, avoir, aller, faire
  1. Imparfait du verbe être : Autrefois, nous _____ (être) → étions
  2. Imparfait du verbe avoir : L'an dernier, tu _____ (avoir) → avais
  3. Imparfait du verbe aller : Chaque été, ils _____ (aller) → allaient
  4. Imparfait du verbe faire : Avant, je _____ (faire) → faisais
  5. Imparfait du verbe être : Hier soir, vous _____ (être) → étiez
Ex 13 · Passé composé avec être
  1. Passé composé du verbe aller : Hier, Léo _____ au parc. (aller) → est allé
  2. Passé composé du verbe aller : Ce matin, Lina _____ à l'école. (aller) → est allée
  3. Passé composé du verbe venir : Dimanche, mes cousins _____ chez nous. (venir) → sont venus
  4. Passé composé du verbe arriver : Les filles _____ en retard. (arriver) → sont arrivées
  5. Passé composé du verbe rester : Paul, tu _____ à la maison. (rester) → es resté
Ex 14 · Futur simple : verbes irréguliers
  1. Futur simple du verbe aller : « Demain, nous … au parc. » → irons
  2. Futur simple du verbe faire : « Tu … un gâteau. » → feras
  3. Futur simple du verbe avoir : « Ils … une surprise. » → auront
  4. Futur simple du verbe venir : « Je … te voir. » → viendrai
  5. Futur simple du verbe voir : « Vous … la mer. » → verrez
