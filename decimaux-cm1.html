  1. 3,47 > 3,74 → Faux 3,47 < 3,74 (dixièmes : 4 < 7)

  3. 4,5 × 10 = 45 → Vrai
  4. 0,099 > 0,1 → Faux 0,099 < 0,1 (dixièmes : 0 < 1)
  5. 3,4 + 1,25 = 4,65 → Vrai

  7. 7 centièmes = 0,07 → Vrai
