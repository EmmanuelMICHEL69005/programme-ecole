Je retiens

🔑 Masculin : le / un · Féminin : la / une
📌 Singulier = un seul · Pluriel = plusieurs (-s souvent)

Corrigé des exercices

Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Reconnaître une phrase correcte
  1. Est-ce une phrase correcte ? "Le chat dort." → oui (majuscule + point + sens)
  2. Est-ce une phrase correcte ? "chien mange le" → non (mots dans le désordre, pas de majuscule)
  3. Est-ce une phrase correcte ? "La petite fille joue dans le jardin." → oui (majuscule + point + sens complet)
  4. Que manque-t-il pour que ce soit une phrase ? "il court vite" → une majuscule au début et un point à la fin
  5. Est-ce une phrase correcte ? "?! le soleil brille" → non (les signes de ponctuation sont à la fin)
Ex 2 · Identifier le nom
  1. Quel est le nom ? "le chat" → chat
  2. Quel est le nom ? "une belle fleur" → fleur
  3. Quel est le nom dans ce groupe ? "il mange une pomme" → pomme
  4. Quel est le nom ? "les enfants courent" → enfants
  5. Quel est le nom ? "un grand chien noir" → chien
Ex 3 · Identifier le verbe
  1. Quel est le verbe ? "Le chat dort sur le canapé." → dort
  2. Quel est le verbe ? "Elle mange une pomme." → mange
  3. Quel est le verbe ? "Les enfants jouent dehors." → jouent
  4. Quel est le verbe ? "Il est content." → est
  5. Quel est le verbe ? "Tu as un beau dessin." → as
Ex 4 · Masculin ou féminin ?
  1. La maison est… "la maison" → féminin (la)
  2. Le soleil est… "le soleil" → masculin (le)
  3. Une école est… "une école" → féminin (une)
  4. Un ballon est… "un ballon" → masculin (un)
  5. La forêt est… "la forêt" → féminin (la)
  6. Le lion est… "le lion" → masculin (le)
Ex 5 · Singulier ou pluriel ?
  1. Singulier ou pluriel ? "des chats" → pluriel (des + -s)
  2. Singulier ou pluriel ? "une fleur" → singulier (une)
  3. Singulier ou pluriel ? "les enfants" → pluriel (les + -s)
  4. Singulier ou pluriel ? "le chien" → singulier (le)
  5. Singulier ou pluriel ? "des maisons" → pluriel (des + -s)
Ex 6 · Vrai ou Faux
  1. Une phrase commence toujours par une majuscule → Vrai
  2. Un nom peut être précédé de "le", "la", "les", "un", "une", "des" → Vrai
  3. "Joue" est un nom → Faux "Joue" est un verbe conjugué (il/elle joue)
  4. "La" devant un nom indique que ce nom est féminin → Vrai
  5. Au pluriel, on ajoute souvent un -s à la fin du nom → Vrai
  6. "Le" peut être placé devant un nom féminin → Faux "Le" est masculin. Devant un nom féminin on utilise "la" (ou "l'" devant une voyelle)
Ex 7 · Associe le mot à sa classe grammaticale
  1. Relie chaque élément à celui qui lui correspond.
    • le / la / les ↔ déterminant
    • chat / maison / école ↔ nom
    • mange / court / est ↔ verbe
    • le (article) ↔ masculin singulier
    • la (article) ↔ féminin singulier
    • les (article) ↔ pluriel
Ex 8 · Trouver le déterminant
  1. Quel est le déterminant ? "le chat mange" → le
  2. Quel est le déterminant ? "une belle maison" → une
  3. Quel est le déterminant ? "des enfants jouent" → des
  4. Quel est le déterminant ? "mon livre est rouge" → mon
  5. Quel est le déterminant ? "cette fleur est belle" → cette
Ex 9 · Choisir le bon déterminant
  1. Quel déterminant choisir ? "___ soleil brille." (masc. sing.) → Le
  2. Quel déterminant choisir ? "___ lune est ronde." (fém. sing.) → La
  3. Quel déterminant choisir ? "___ enfants jouent." (pluriel) → Les
  4. Quel déterminant choisir ? "Je vois ___ fleur rouge." (fém. sing. indéfini) → une
  5. Quel déterminant choisir ? "Il y a ___ arbres dans le jardin." (plur. indéfini) → des
Ex 10 · Masculin ou féminin ? Trier les groupes nominaux
  1. Classe chaque groupe nominal : masculin ou féminin ?
    • Masculin : le soleil, un livre, le chien, mon stylo
    • Féminin : la lune, une école, la chatte, ma maison
Ex 11 · Compter les mots d'une phrase
  1. Combien de mots y a-t-il dans cette phrase ? "Le bébé rit." → 3
  2. Combien de mots y a-t-il dans cette phrase ? "Papa lit un livre." → 4
  3. Combien de mots y a-t-il dans cette phrase ? "Lina mange une pomme rouge." → 5
  4. Combien de mots y a-t-il dans cette phrase ? "Il pleut." → 2
  5. Combien de mots y a-t-il dans cette phrase ? "Le petit chien joue dans le jardin." → 7
Ex 12 · Les noms propres et la majuscule
  1. Quel mot est un prénom ? → Léa
  2. Quel mot prend toujours une majuscule ? → Paris
  3. Quel prénom est bien écrit ? → Tom
  4. Quel mot est le nom d'une ville ? → Lyon
  5. Quelle phrase est bien écrite ? → Sami joue.
Ex 13 · Il, elle, ils ou elles ?
  1. Par quel mot peux-tu remplacer « Léa » ? "Léa chante." → elle
  2. Par quel mot peux-tu remplacer « Le lapin » ? "Le lapin saute." → il
  3. Par quel mot peux-tu remplacer « Les garçons » ? "Les garçons courent." → ils
  4. Par quel mot peux-tu remplacer « Les filles » ? "Les filles dansent." → elles
  5. Par quel mot peux-tu remplacer « Papa » ? "Papa cuisine." → il
