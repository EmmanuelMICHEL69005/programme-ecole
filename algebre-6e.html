Ex 1 · Lire et écrire des expressions
  1. Comment s'écrit "3 fois un nombre x" en algèbre ? → 3x
  2. "Le double d'un nombre y augmenté de 5" s'écrit… → 2y + 5
  3. L'expression "4a − 3b" contient… → 2 termes (4a et −3b)
  4. Dans l'expression 5x + 7, si on remplace x par 0, on obtient… → 7
Ex 2 · Calculer la valeur d'une expression
  1. Calcule 3x + 2 pour x = 4 : 3x + 2 si x = 4 → 14
  2. Calcule x² − 1 pour x = 3 : x² − 1 si x = 3 → 8
  3. Calcule 2a + 3b pour a = 5 et b = 2 : 2a + 3b si a=5, b=2 → 16
  4. Calcule (n+1)(n−1) pour n = 5 : (n + 1)(n − 1) si n=5 → 24
Ex 3 · Tester des solutions d'équations
  1. Est-ce que x = 5 est une solution de x + 7 = 12 ? x + 7 = 12 → Oui (5 + 7 = 12 ✓)
  2. Est-ce que x = 6 est une solution de 2x = 14 ? 2x = 14 → Non (2 × 6 = 12 ≠ 14)
  3. Quelle valeur de x vérifie 3x − 1 = 8 ? 3x − 1 = 8 → x = 3 (car 3×3−1=8)
  4. Quelle valeur de x vérifie x/2 + 1 = 4 ? x/2 + 1 = 4 → x = 6 (car 6/2+1=4)
Ex 4 · Résoudre de petites équations
  1. Résous x + 9 = 15 : x + 9 = 15 → x = 6
  2. Résous 4x = 28 : 4x = 28 → x = 7
  3. Résous x − 5 = 11 : x − 5 = 11 → x = 16
  4. Léa a x billes. Elle en donne 8 et il lui en reste 15. Quelle équation représente cette situation ? → x − 8 = 15
Ex 5 · Écrire et calculer avec des lettres
  1. Calcule 5x − 3 pour x = 2 : 5x − 3 si x = 2 → 7
  2. "Un nombre n diminué de 4" s'écrit… → n − 4
  3. Calcule 2(x + 3) pour x = 5 : 2(x + 3) si x = 5 → 16
  4. Résous x + 12 = 20 : x + 12 = 20 → x = 8
  5. Un ticket coûte 4 €. Quel est le prix de n tickets, en euros ? → 4n
Ex 6 · Formules et expressions
  1. Le périmètre d'un carré de côté c est 4 × c. Calcule-le pour c = 7 cm. → 28 cm
  2. Calcule 6 + 2x pour x = 5 → 16
  3. Calcule 10 − x pour x = 3 → 7
  4. Tom a n ans. Sa sœur a 3 ans de plus que lui. L'âge de sa sœur s'écrit… → n + 3
  5. Un rectangle a pour longueur L et pour largeur l. Son périmètre s'écrit… → 2 × (L + l)
