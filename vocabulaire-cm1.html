Pour les parents : toutes les questions de la page avec leur réponse, pour vérifier ou refaire une séance sur papier. Ouvrez un exercice pour voir son corrigé.

Ex 1 · Synonymes
  1. Quel est un synonyme de "rapide" ? "rapide" → vif
  2. Quel est un synonyme de "joyeux" ? "joyeux" → gai
  3. Quel est un synonyme de "courageux" ? "courageux" → brave
  4. Quel est un synonyme de "demeure" ? "demeure" → maison
  5. Quel est un synonyme de "aider" ? "aider" → secourir
  6. Quel est un synonyme précis pour "regarder attentivement" ? "regarder" → observer
Ex 2 · Antonymes
  1. Quel est l'antonyme de "généreux" ? "généreux" → avare
  2. Quel est l'antonyme de "victoire" ? "victoire" → défaite
  3. Quel est l'antonyme de "monter" ? "monter" → descendre
  4. Quel est l'antonyme de "clair" ? "clair" → sombre
  5. Quel est l'antonyme de "construire" ? "construire" → démolir
Ex 3 · Familles de mots
  1. Quel mot de la même famille ? "boulangerie" → boulanger
  2. Quel mot appartient à la même famille ? "fleur" → fleurir
  3. Quel mot appartient à la famille de "pêcher" ? "pêcher" → pêcheur
  4. Quel mot appartient à la famille de "heureux" ? "heureux" → bonheur
  5. Quel mot n'appartient PAS à la famille de "livre" ? "livre" → liberté
Ex 4 · Préfixes et suffixes
  1. Que signifie le préfixe "im-" ? "im-possible" → non, contraire
  2. Que signifie le préfixe "re-" ? "re-faire" → de nouveau
  3. Que signifie le suffixe "-eur" ? "chant-eur" → qui fait l'action
  4. Que signifie le suffixe "-al" ? "nation-al" → relatif à
  5. Que signifie le préfixe "in-" ? "in-utile" → contraire, sans
Ex 5 · Sens propre ou figuré ?
  1. Sens de "brisé" dans cette phrase : "Il a le cœur brisé." → figuré (il est triste)
  2. Sens de "brisé" dans cette phrase : "Le vase est brisé." → propre (cassé physiquement)
  3. Sens de "dévore" dans cette phrase : "Il dévore ses livres." → figuré (il lit très vite)
  4. Sens de "dévore" dans cette phrase : "Le lion dévore sa proie." → propre (manger)
  5. Sens de "douce" dans cette phrase : "Cette musique est douce." → figuré (agréable à entendre)
Ex 6 · Vrai ou Faux
  1. Un synonyme est un mot de même sens mais pas toujours interchangeable → Vrai
  2. "Dé-faire" — le préfixe "dé-" signifie "faire de nouveau" → Faux "Dé-" signifie l'inverse, l'action contraire : défaire = l'opposé de faire
  3. "Bonheur" et "malheur" sont des antonymes → Vrai
  4. "Avoir le cafard" est une expression au sens propre → Faux "Avoir le cafard" est au sens figuré — cela signifie être triste, pas avoir un insecte
  5. "Chanter", "chanson", "chanteur" appartiennent à la même famille → Vrai
  6. Un suffixe se place avant le radical du mot → Faux Le suffixe se place APRÈS le radical ; le préfixe se place avant
Ex 7 · Associe le mot à son synonyme
  1. Relie chaque élément à celui qui lui correspond.
    • rapide ↔ vif / leste
    • courageux ↔ brave / vaillant
    • commencer ↔ débuter / entamer
    • terminer ↔ finir / achever
    • grand ↔ immense / vaste
    • triste ↔ chagriné / mélancolique
Ex 8 · Sens propre ou figuré ?
  1. Sens de l'expression dans cette phrase : "Il a un cœur de pierre." → figuré (il est insensible)
  2. Sens de "pierre" dans cette phrase : "La pierre est froide." → propre
  3. Sens de l'expression dans cette phrase : "Elle a la langue bien pendue." → figuré (elle parle beaucoup)
  4. Sens de l'expression dans cette phrase : "Il tire la langue." → propre
  5. Sens de l'expression dans cette phrase : "Ce problème est une montagne." → figuré (le problème est énorme)
Ex 9 · Identifier le préfixe et son sens
  1. Que signifie ce préfixe ? "pré-" dans "prévoir" → avant (prévoir = voir avant)
  2. Que signifie ce préfixe ? "sur-" dans "surcharger" → au-dessus / trop (surcharger = charger trop)
  3. Que signifie ce préfixe ? "anti-" dans "antialgique" → contre (anti = contre)
  4. Que signifie ce préfixe ? "bi-" dans "bicyclette" → deux (bi = deux)
  5. Que signifie ce préfixe ? "inter-" dans "international" → entre (entre les nations)
Ex 10 · Associe chaque mot à son antonyme
  1. Relie chaque élément à celui qui lui correspond.
    • courage ↔ lâcheté
    • patience ↔ impatience
    • victoire ↔ défaite
    • clarté ↔ obscurité
    • générosité ↔ avarice
    • liberté ↔ captivité

  1. Quel est le mot générique ? "pomme, poire, banane" → des fruits
  2. Quel est le mot générique ? "chaise, table, armoire" → des meubles
