Je retiens

🔁 (a + b)² = a² + 2ab + b² · (a − b)² = a² − 2ab + b²
✖️ (a − b)(a + b) = a² − b²
⚖️ Produit nul : si A × B = 0 alors A = 0 ou B = 0 · une inéquation se résout comme une équation (sens du signe si on divise par un négatif)
